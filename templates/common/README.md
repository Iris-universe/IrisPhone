# __DISPLAY_NAME__

An iPhone app made with [IrisPhone](https://github.com/Iris-universe/IrisPhone): no Mac needed.

```sh
irisphone build   # compile
irisphone run     # build + install on the iPhone plugged in by USB
irisphone logs    # see what the app prints
```

Working with [Claude Code](https://claude.com/claude-code)? Open this folder and ask for features:
`CLAUDE.md` and `.mcp.json` let Claude build, install and read the logs by itself.
